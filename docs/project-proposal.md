# Project Proposal

## Project Title

MediVault: Web-Based Smart Pharmacy Inventory & Prescription Availability
Checker

## Problem Statement

Pharmacy staff often need to check medicine availability from prescriptions
manually. This can be slow when prescriptions contain unclear text, brand names,
generic names, or different medicine strengths.

## Proposed Solution

MediVault is a responsive web application that stores medicine inventory in a
cloud database. Pharmacy staff can search inventory records and check medicines
from manually entered prescription text or text extracted from uploaded
prescription images.

The application shows availability, stock quantity, price, and possible matches.
It is designed to support staff verification rather than provide medical advice.

## Objectives

- Build a responsive pharmacy inventory web application
- Store medicine inventory in a cloud PostgreSQL database
- Search medicines by medicine, generic, or brand name
- Check manually entered prescription text against inventory
- Extract editable prescription text from images with OCR
- Show exact matches and possible matches for unclear text
- Display availability, price, and stock quantity
- Highlight low-stock and expiry statuses
- Deploy the application using a free hosting platform

## Target Users

- Pharmacy staff
- Pharmacy owners
- Small pharmacy businesses

## Scope

The project covers inventory management, prescription availability checking,
OCR-assisted text extraction, reports, and staff authentication. It does not
include billing, payments, sales, or medical diagnosis.

## Expected Outcome

A deployed web application where pharmacy staff can manage medicine inventory
and quickly verify whether medicines listed in prescriptions are available.
